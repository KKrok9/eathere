# EATHERE - Restaurant Management System

## Project Overview
EATHERE is a restaurant management system developed as part of an engineering thesis project. The system aims to streamline daily restaurant operations, such as managing orders, reservations, menu items, and customer service. The application is designed to provide an intuitive user interface and a scalable backend architecture.

## Features
- Order management (adding, editing, tracking order status)
- Reservation management
- Menu management (adding, editing, removing menu items)
- Customer management and support
- Reporting and analytics for restaurant performance

## Technologies Used
- **C# .NET** - Backend development, providing the core logic of the system.
- **Angular** - Frontend framework for building a responsive and dynamic user interface.
- **MSSQL** - Database management system used for storing and managing restaurant data.
- **Entity Framework** - ORM (Object-Relational Mapping) tool used for database access and manipulation.
- **ASP.NET Core** - Web framework used for building the RESTful API backend.
- **Bootstrap** - CSS framework for responsive and mobile-first front-end design.

## Getting Started
### Prerequisites
- .NET SDK installed
- Node.js and npm (Node Package Manager) installed
- SQL Server installed and configured
